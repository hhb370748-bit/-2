# مصطفى كطان للهواتف والصيانة

موقع متجر ومركز صيانة مصطفى كطان لبيع الهواتف والشاشات وقطع الغيار والإكسسوارات.

## Run Locally

**المتطلبات:** Node.js


1. تثبيت الاعتمادات:
   `npm install`
2. تشغيل الموقع محليًا:
   `npm run dev`

## النشر

المشروع مجهز للنشر على GitHub Pages عبر ملف `.github/workflows/deploy.yml`.
